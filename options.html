Voice Corrector for Autodarts

Pick a word the caller and TV rarely say.

The button "correct next" presses, exactly as it reads in Autodarts. Several labels separated by commas, e.g. Next, Weiter.

Confirms a correction in Autodarts right after it's made.

Only when a correction fails because of it. Your command is repeated after the reload.

The settings file holds the words speech recognition mishears, e.g. "dot" for "dart".

How to use

  • Start listening with the Start button in the panel on the match page, or Alt+V.
  • correct triple twenty: last dart becomes T20
  • correct second double 16: dart 2 becomes D16
  • correct the first dart to 5: dart 1 becomes S5
  • correct bullseye / outer bull / miss
  • correct undo: reverts the last voice correction
  • correct next: presses the Next / Weiter button, e.g. when pulling out the darts wasn't detected
  • correct board calibrate / board reset: presses Calibrate / Reset in Board control
  • Move the panel by dragging its title; double-click the title to put it back in the corner.
  • Short forms work too: T20, D16, treble 19.
  • If something isn't understood, the panel shows what was heard. Add misheard words to the settings file.
